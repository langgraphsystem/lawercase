## 📱 Telegram Bot - Пошаговая инструкция

### Шаг 1: Первый запуск
```
1. Найти бота → @your_eb1a_bot
2. Отправить → /start
3. Получить приветствие ✓
```

### Шаг 2: Основные команды (топ-5)
```
/intake_start    ← НАЧНИТЕ С ЭТОГО! Анкетирование
/help            ← Список всех команд
/eb1_analyze     ← Анализ ваших шансов
/case_create     ← Создать формальный кейс
/status          ← Проверить статус системы
```

### Шаг 3: Процесс анкетирования (8 блоков)
```
Блок 1: Основная информация (имя, дата, гражданство)
Блок 2: Образование (степени, университеты)
Блок 3: Карьера (позиции, компании)
Блок 4: Достижения (награды, публикации, патенты)
Блок 5: Членство (организации)
Блок 6: Критическая роль (судейство, рецензирование)
Блок 7: Медиа (упоминания в прессе)
Блок 8: Коммерческий успех (доход от работы)
```

### Шаг 4: Навигация
```
⏭ Пропустить   - Пропустить вопрос
⏸ Пауза        - Сохранить прогресс и выйти
🔙 Назад       - Вернуться к предыдущему вопросу
▶ Продолжить   - Перейти к следующему блоку
```

### Шаг 5: После анкетирования
```
/eb1_analyze        → Полный анализ критериев
/generate_letter    → Шаблоны рекомендательных писем
/case_create        → Открыть официальный кейс
```

## 🔧 API - Пошаговая инструкция

### Шаг 1: Получить JWT токен
```bash
curl -X POST \
  https://refreshing-reprieve-production-9802.up.railway.app/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "lawyer@eb1a.com",
    "password": "demo1234"
  }'

# Ответ:
# {
#   "access_token": "eyJhbGc...",
#   "token_type": "bearer",
#   "expires_in": 86400,
#   "user_id": "lawyer-001",
#   "roles": ["lawyer"]
# }
```

### Шаг 2: Основные эндпоинты
```bash
# Проверка здоровья системы
GET /health
GET /ready

# Запрос к агенту
POST /v1/ask
{
  "query": "Analyze my EB-1A chances"
}

# Поиск в памяти
POST /v1/search
{
  "query": "patent applications",
  "top_k": 5
}

# Управление кейсами
POST /api/v1/cases         # Создать
GET  /api/v1/cases/{id}    # Получить
PUT  /api/v1/cases/{id}    # Обновить
DELETE /api/v1/cases/{id}  # Удалить
```

### Шаг 3: Streaming через AG-UI
```bash
curl -X POST \
  https://refreshing-reprieve-production-9802.up.railway.app/agui/run \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Analyze criteria",
    "case_id": "case-123",
    "stream": true
  }'

# Ответ через Server-Sent Events (SSE):
# event: RUN_START
# data: {"run_id": "run-123"}
#
# event: TEXT_CHUNK
# data: {"text": "Based on your profile..."}
#
# event: RUN_COMPLETE
# data: {"status": "success"}
```

## 📊 10 Критериев EB-1A

Система анализирует ваш профиль по этим критериям:

```
1. ✅ Награды национального/международного значения
2. ✅ Членство в ассоциациях с высокими требованиями
3. ✅ Публикации о вас в крупных СМИ
4. ✅ Судейство работ других в вашей области
5. ✅ Оригинальные научные/бизнес/художественные вклады
6. ✅ Авторство научных статей в профессиональных изданиях
7. ✅ Работы выставлялись/демонстрировались публично
8. ✅ Лидирующая/критическая роль в известных организациях
9. ✅ Высокая зарплата по сравнению с коллегами
10. ✅ Коммерческий успех в искусстве/исполнительской деятельности
```

**Для одобрения:** Нужно соответствовать **минимум 3 из 10** критериям.

## ⚠️ Распространенные проблемы

| Проблема | Решение |
|----------|---------|
| "Access denied" в Telegram | Добавить user_id в `TELEGRAM_ALLOWED_USERS` |
| "401 Unauthorized" | Токен истек - получить новый через `/auth/login` |
| "503 Service Unavailable" | Проверить `/health` endpoint |
| Бот не отвечает | Попробовать `/start` заново |
| Web UI не загружается | Очистить кэш браузера |
