## ❓ Частые вопросы

### Q: Сколько времени займет анкетирование?
**A:** 15-30 минут. Можно прервать в любой момент и продолжить позже.

### Q: Что делать, если я не знаю ответ на вопрос?
**A:** Нажмите кнопку "⏭ Пропустить". Вы сможете добавить информацию позже.

### Q: Мои данные в безопасности?
**A:** Да. Все данные хранятся в зашифрованном виде в Supabase/PostgreSQL.

### Q: Можно ли редактировать ответы?
**A:** Да. Используйте кнопку "🔙 Назад" в Telegram или отредактируйте кейс в Web UI.

### Q: Сколько стоит использование?
**A:** MVP версия бесплатна для демонстрации. Для production требуется подписка.

### Q: Какие языки поддерживаются?
**A:** Русский (основной), Английский. Документы генерируются на английском для USCIS.

### Q: Могу ли я работать одновременно через Telegram и Web?
**A:** Да. Данные синхронизируются между всеми интерфейсами.

## 🆘 Помощь и поддержка

### Не работает что-то?

1. **Проверьте статус системы:**
   ```
   Telegram: /status
   Web: https://refreshing-reprieve-production-9802.up.railway.app/health
   ```

2. **Telegram бот не отвечает:**
   - Проверьте, что вы авторизованы (ваш user_id в `TELEGRAM_ALLOWED_USERS`)
   - Попробуйте /start заново

3. **Web UI не загружается:**
   - Очистите кэш браузера
   - Проверьте, что backend доступен: `/health`

4. **API возвращает 401:**
   - Токен истек (24 часа)
   - Получите новый через `/auth/login`
